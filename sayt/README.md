# Сайт Archiwood (archiwood.spb.ru)

Новый сайт вместо Тильды. Это обычные статические страницы: работают быстро, бесплатно размещаются на Cloudflare Pages и хорошо индексируются поисковиками.

## Что где лежит

| Путь | Что это |
|---|---|
| `content/site.mjs` | **Все тексты**: контакты, проекты, отзывы, принципы. Правки сайта — здесь. |
| `src/style.css` | Оформление (один файл вместо стилей из 16 блоков Тильды) |
| `src/app.js` | Анимации, слайдеры, меню, просмотр фото. Без Swiper и Fancybox. |
| `static/logo.svg` | Логотип (сейчас заглушка, замените на настоящий) |
| `static/img/` | Готовые сжатые фото (WebP), их делает `tools/foto.py` |
| `foto/` | Ваши исходные фото. В git не хранятся (слишком тяжелые). |
| `FOTO.md` | **Список всех фото**: какой файл, какого размера, где на сайте |
| `build.mjs` | Сборщик: собирает страницы в `dist/` |

## Страницы

- `/` — главная: первый экран, «Кто мы», галерея проектов, отзывы, контакты
- `/o-kompanii/` — о компании: принципы работы, главное обещание
- `/proekty/` — все проекты: реализованные и в работе
- `/proekty/<проект>/` — отдельная страница каждого реализованного проекта с галереей

Старые адреса Тильды перенаправляются: `/2` → `/o-kompanii/`, `/3` → `/proekty/`, `/3?open=repino1` → страница проекта.

## Как обновить сайт

```
python3 sayt/tools/foto.py   # если добавились или поменялись фото
node sayt/build.mjs          # собрать сайт в sayt/dist
```

Добавить проект: допишите его в `projects` в `content/site.mjs` (и в `featured`, если он нужен в слайдере на главной), положите фото в `foto/proekty/<id>/`, запустите две команды выше.

## Размещение (Cloudflare Pages)

1. Cloudflare → Workers & Pages → Create → Pages → подключить этот репозиторий.
2. Build command: `node sayt/build.mjs`, Build output directory: `sayt/dist`.
3. Custom domains → `archiwood.spb.ru`. Тильду не отключать, пока новый сайт не проверен на временном адресе.
4. Яндекс Вебмастер и Google Search Console: добавить сайт и отправить `https://archiwood.spb.ru/sitemap.xml`.
5. Номер Яндекс Метрики вписать в `site.metrika` в `content/site.mjs`.
