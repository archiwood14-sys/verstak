## 8. Предложения для каталога и бота
### Проект (порядок проверки)
1. **По пути, если файл в корне проектов:** `1 ОЛИМПИЙСКИЙ` → Олимпийский; `2 РАЗДОРЫ` → Раздоры-двери; `3/4/5 РАЗДОРЫ. МЕБЕЛЬ` → Раздоры-мебель. Путь главнее имени.
2. **По коду в имени:** `ИР-` → Раздоры-мебель; `д-N.N` → Раздоры-двери; ИП / TGPLU → Плющиха; ИО / И.О → Озерки; ИИ / TGILI → Ильинка; ИМ / TGMED → Медное Озеро; ZAH → Захарьевская; TGRAZ → Раздоры.
3. **По словам** (имя файла, папка письма, тема): таблица из раздела 3. Порядок проверки: Олимпийский-маркеры → Раздоры-мебель → Раздоры-двери, потому что «двер» и «портал» есть в обоих проектах.
4. **Никогда не определять проект по:** «Лигнум» (наше юрлицо), людям olimpik.ru (Зверева, Туманова, Степаненко, Завзянова, Анисина), «Зиновьев» без суммы или «Раздоры». Олег Зиновьев — поставщик со счетами. «Наталья»: Арефьева — счета, «Наталья (Киевская площадь)» — Олимпийский.
5. Telegram — по chat id из таблицы раздела 4.
6. Иначе «Общее / не определено». Сейчас это около 54 % писем.
